# CodeAlpha_EDA_Visualization

Exploratory Data Analysis and Data Visualization on an e-commerce orders dataset (200,000 orders, 50 columns, from Kaggle).

**CodeAlpha Data Analytics Internship: Task 2 (EDA) and Task 3 (Data Visualization)**

## What I did
- Loaded and understood the data (structure, types, summary statistics)
- Cleaned it (duplicates, missing values, date conversion)
- Explored sales, profit, returns, outliers and correlations
- Tested a hypotheses (discount vs profit)
- Built 7 charts with Matplotlib and Seaborn

## Key findings
1. Three categories (Electronics, Mobile Phones, Computers & Accessories) make about 72% of net sales.
2. Higher discounts reduce profit; at 40% the average order loses money.
3. About 12% of orders are cancelled or returned.
4. About 23% of orders have negative profit.
